# 輝玉祭2026 コンピューター部ゲームランチャー

2026用に更新。

## ゲームの追加

`launcher-game/games/<genre>/<game-name>/` にゲームを配置すると、起動時に
`game_info.json` が再生成されます。各ゲームの設定は `launcher_meta.txt` に記述します。

`project_type` は `exe`、`scratch`、`movie`、`difficulty` は `easy`、
`normal`、`hard` のいずれかです。エントリーファイルやサムネイルがないゲームは
警告として報告され、ほかの正常なゲームだけが一覧へ登録されます。


`launcher_meta.txt` の書式:
```
1行目: ゲームの表示名
2行目: 起動するファイル名 (`Game.exe`など)
3行目: ゲームの種類 (exe/scratch/movie)
4行目: 難易度 (easy/normal/hard)
5行目以降: 説明文
```

サムネイルはゲームフォルダ直下へ `thumbnail.png` など、拡張子を問わず
`thumbnail` というファイル名で配置してください。説明文の改行はそのまま画面へ反映されます。


## 展示中の動作

- 人数選択後にAPIから体験時間を取得します。取得できない場合は
  `launcher-settings.json` の `timer`（既定360秒）を使用します。
- EXEゲーム中もランチャーは背景に表示されますが、クリックやフォーカスを受け取りません。
- 右上の常時最前面ウィンドウから、ゲームを終了してランチャーへ戻れます。
- 体験時間終了時はゲームを強制終了せず、右上のウィンドウに終了案内を表示します。
